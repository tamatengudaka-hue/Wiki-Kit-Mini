## Make it your own

This section spans the full width again.

1. Copy the sample directory to create your article.
2. Rewrite each Markdown file.
3. Set the order and layout in `config.json` using `rows`.
4. Register the title, file path and tags in `content/articles.json`.

An article can contain up to five Markdown files. Each row can have one or two files. Fewer files are fine too.

Paths are relative to the split configuration's directory. External URLs, paths containing `..` and duplicate file entries are not allowed.

### The usual wiki features still work

- **Search:** search for “two columns” to find this article as one result.
- **Contents:** headings from every Markdown file share one table of contents.
- **Tags:** tags belong to the article and are not automatically translated.
- **Wiki links:** [[welcome#Add an article|read how to add a normal article]].
- **Code:** copy the complete configuration using its copy button.
